# Contributing

This repository holds the public documentation for Livuma's APIs and MCP server. The documentation
is maintained by the Livuma team and mirrors what the live services do, so we keep it in sync
ourselves rather than merging external pull requests.

**Found a mistake, an outdated example or an endpoint that behaves differently than described?**

- Open an issue in this repository with the endpoint or tool name, what you sent, what you got
  back and what you expected. Redact your API key and any personal data.
- Questions that are not documentation bugs (account access, API keys, listings, bookings) go to
  hello@livuma.com or the WhatsApp support link inside the docs.

Pull requests are welcome for typos and wording, but anything that changes what the docs claim
about the API will be verified against the live service before it is merged.
