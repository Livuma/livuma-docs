# Security

If you believe you have found a security vulnerability in Livuma (livuma.com), its APIs or its
MCP server, please report it privately.

- Email: hello@livuma.com, subject line starting with `SECURITY`
- Include the affected URL or endpoint, steps to reproduce, and the impact you believe it has.
- Do not access, modify or delete data that is not yours, and do not run automated scanners
  against production beyond what is needed to demonstrate the issue.

We acknowledge reports within a few business days and keep you informed while the issue is
fixed. Please give us reasonable time to address a report before disclosing it publicly.

**API keys:** if you suspect your own `livuma_sk_…` key has leaked, regenerate it immediately in
Profile → Security → API Access on livuma.com. The old key stops working at once.
